# 钢线 1944 · STEEL LINE

一款直接跑在浏览器里的二战 RTS 原型。

**2 km × 2 km** 等高线战场，三阵营混战、背水一战、工事与补给、步兵装备、装甲对抗，以及会隐蔽、会侦察、会布设障碍的战场单位。

无需安装，打开即可玩。

当前版本：**v0.8.7**

## 游戏模式

### 混战模式

蓝、红、绿三支合成部队在同一张地图上争夺黄圈。

- 黄圈内净优势单位会持续获得经验与分数
- 率先累计 **100,000 黄圈经验**的阵营获胜
- 无限难度没有胜利条件，适合长期混战
- 难度越高，敌方经验、火力与进攻欲望越强
- 关键经验节点会出现 BOSS
- AI 空袭会以小编队出现，随对局时间增加规模

### 背水一战

蓝队固守随机黄圈，红队分波进攻。

- 守住黄圈直到目标时间即获胜
- 黄圈被红队占领即失败
- 每 5 波加入 BOSS；第 30 波双 BOSS，第 50 波起三 BOSS
- 红队会呼叫空袭，波次越高空袭规模越大
- 无限难度没有固定结束时间，可主动结算或存档

### 试验场

无敌人、无波次，用于熟悉单位、装备、工事与 BOSS。

- 可自由使用测试卡包
- 可放置标靶、刷新黄圈、召唤 BOSS
- 可开关战争迷雾

### 工程车操作

1. 选中工程车
2. 在右侧详情面板选择一种工程模式：
   - 反步兵雷
   - 反坦克雷
   - 铁丝网

3. 右键移动，车辆会沿行驶路线自动布设
4. 再次点击当前模式可关闭

## 单位说明

### 步兵班

- 耐久 **300**，视野 **350m**，射程 **160m**，速度 **7.2m/s**
- 基础武器为步枪 / 轻机枪
- 可携带最多 **6 件装备**
- 可进入灌木、树林、工事获得掩护
- 可占领阵地；步兵在占领区获得更高闪避
- 可急行军，满体力约 **300m**
- 轻武器无法击穿坦克，需要火箭筒、反坦克手雷、反坦克炮或坦克炮

### 装甲车

- 耐久 **150**，视野 **200m**，射程 **180m**，速度 **14m/s**
- **30mm 机炮**，10m 溅射
- 对步兵和轻装甲目标压制力强
- 没有对空能力
- 装甲薄，正面硬冲反坦克火力会很快被击毁

### 中型坦克

- 耐久 **400**，视野 **190m**，射程 **190m**，速度 **9.5m/s**
- **75mm 主炮** + MG42 并列机枪
- 对步兵用机枪，对装甲用主炮
- 综合能力最均衡的装甲单位

### 重型坦克

- 耐久 **520**，视野 **110m**，射程 **210m**，速度 **8.5m/s**
- **88mm 主炮** + MG42
- 正面装甲极强，步枪、机炮、防空炮无法击穿
- 视野较差，需要友军提供目标指示

### 轻型反坦克炮

- 耐久 **90**，视野 **160m**，射程 **190m**，速度 **6.5m/s**
- **75mm Pak 40**，高穿甲
- 原地 5 秒不开火可进入隐蔽
- 移动或开火会解除隐蔽
- 适合埋伏在道路、树林边缘和工事区

### 火炮

- 耐久 **65**，视野 **160m**，射程 **600m**，最小射程 **70m**
- 需要先收炮、移动、再架设
- 架设完成前不会索敌或开火
- 可对指定区域进行 60 秒火力压制
- 适合拆除工事和压制密集步兵

### 重型火炮

- 耐久 **85**，视野 **160m**，射程 **800m**，最小射程 **100m**
- 更长的收炮 / 架设时间
- 单发伤害和溅射更高
- 移动缓慢，需要提前选好阵地

### 防空车

- 耐久 **90**，视野 **150m**，对地射程 **160m**，对空射程 **600m**，速度 **13m/s**
- **20mm 防空炮**，20 发弹夹
- 自动优先攻击敌方飞机
- 没有飞机时才会对地射击

### 自行火箭炮

- 耐久 **110**，视野 **200m**，射程 **700m**，速度 **10m/s**
- 十联装火箭炮，5 秒内逐发速射 10 发
- 默认停火，需要手动点射
- 装填时间长，暴露后很脆弱
- 适合在安全距离覆盖黄圈或工事

### 指挥车

- 耐久 **120**，视野 **450m**，速度 **12m/s**
- 无武装
- Shift + 右键建立直径 **300m** 的持续侦察区
- 指挥车移动后侦察区失效
- 原地 5 秒可进入隐蔽
- 持续侦察圈可以发现普通隐蔽步兵，但无法发现幽灵状态

### 工程车

- 耐久 **220**，视野 **240m**，速度 **12m/s**；激活工程模式时速度 -20%
- 无武装
- 可布设反步兵雷、反坦克雷、铁丝网、拒马
- 车身上显示工程值进度条
- 消耗工程值，工程值可在己方补给圈补充
- 可以消耗工程值修复强化工事残骸；但不能建立第一次强化工事，必须先由工兵步兵建立
- 铁丝网 / 拒马节点会自动连成线
- 每个节点 **1500 HP**，摧毁节点即可断线

## 步兵装备

| 装备 | 作用 |
| --- | --- |
| **机枪 MG42** | 高射速，使用步兵班弹药 |
| **迫击炮** | 300m 间瞄，停止移动后开火，可直击轻装甲 |
| **火箭筒 Panzerschreck** | 200m，对装甲高伤，3 发，散布较大，不吃高地射程加成 |
| **反坦克手雷** | 100m，高穿甲，对装甲优先 |
| **手榴弹** | 100m，35m 溅射，对密集步兵有效 |
| **狙击侦察小组** | 视野 +100m，对步兵和轻装甲高伤，可创建一次灌木隐蔽 |
| **伪装服** | 在灌木 / 树林停火 1 秒进入幽灵状态 |
| **应急医疗包** | 自动回血，医疗量耗尽后消失 |
| **工兵装备** | 构筑 / 修复强化工事，或建造一次野战工事区 |

装备会占用步兵物品栏。部分武器使用步兵班弹药，火箭筒和反坦克手雷使用自身弹药。

## 隐蔽与侦察

- 步兵在灌木 / 树林停火 **1 秒**后进入隐蔽
- 隐蔽提供额外 **25% 闪避**
- 敌人逼近 **50m** 或步兵开火会暴露
- 伪装服 + 灌木 / 树林可进入 **幽灵状态**，额外 **35% 闪避**
- 幽灵状态无法被普通侦察发现
- 指挥车持续侦察圈可以发现普通隐蔽步兵，但看不见幽灵
- 侦察机提供 20 秒侦察区，同样无法发现幽灵
- 反坦克炮、指挥车原地 5 秒可进入隐蔽

## 工程车与障碍

### 反步兵雷

只触发敌方步兵，适合封锁灌木、树林和占领区入口。

### 反坦克雷

只触发敌方载具，适合埋在道路、桥梁和装甲必经路线。

### 铁丝网

- 节点自动连成线
- 步兵不能跨越铁丝网
- 载具可以碾压铁丝网，直接破坏节点
- 适合阻挡步兵渗透

### 拒马

- 节点自动连成线
- 载具不能跨越拒马
- 步兵可以跨越拒马
- 适合封锁道路和坦克通道

### 绕行与拆除

- 单位会优先寻找绕行路线
- 所有道路被封死时，会自动射击敌方障碍拆除
- 也可以右键点击敌方铁丝网 / 拒马直接攻击

## 工事、补给与卡包

### 工事

- 占领工事区后，工兵可以构筑强化工事
- 工事区可部署机枪碉堡、迫击炮阵地、反坦克炮阵地、88 防空炮阵地
- 工事会独立索敌开火，但目标需要友军或侦察提供视野
- 每个工事区最多部署 4 座工事
- 被摧毁的工事可由工兵修复

### 补给

- 补给卡会呼叫绿色运输机
- 投下直径 **200m** 的补给圈
- 中心补给箱有 500 HP，可被炮火或空袭击毁
- 补给圈补充弹药、医疗步兵、维修车辆
- 工程车也可以在补给圈补充工程值

### 卡包

- 升级获得抽卡机会
- 每次从 5 张候选卡中选择 1 张
- 单位包、装备包、工事包会自动开出对应卡片
- 分数可以购买额外抽卡
- 卡片可以拖到单位或战场使用

## 战术提示

1. **不要只出坦克**：步兵提供视野和占领，坦克提供突破，火炮提供压制。
2. **先侦察再进攻**：指挥车的持续侦察圈能提前发现埋伏。
3. **利用掩体**：灌木、树林、村庄和工事区都能提供减伤或闪避。
4. **反装甲要分层**：火箭筒、反坦克手雷、反坦克炮和坦克炮各有射程与用途。
5. **工兵很重要**：强化工事能守住占领区，工程车能封锁道路。
6. **注意补给**：弹药耗尽的高价值单位会变成废铁。
7. **火炮不要贴脸**：保持距离，提前架设，避免被装甲突袭。
8. **观察小地图**：黄圈、占领区和敌军动向都在小地图上。
9. **用暂停思考**：空格暂停后可以慢慢选择单位和下达命令。
