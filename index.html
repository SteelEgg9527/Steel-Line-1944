作战简报 · 圣洛村

1944 年 6 月 10 日 · 三军混战 · 无限重生

1944 年 6 月，西欧战场。蓝、红、绿三支合成部队在 2 km × 2 km 战场上争夺黄圈。 普通/困难累计 100,000 黄圈经验获胜；无限难度无胜利条件。 BOSS与AI单位上限随难度变化；黄圈与占领区持续提供经验、分数，分数可购买额外抽卡。

模式
难度

战场

你的连队（蓝队）

  • 步兵班 × 3
  • 装甲车 × 2
  • 中型坦克 × 1

其他阵营

  • 红队 / 绿队 · 初始6单位基础连队
  • AI单位上限：简单14 / 普通20 / 困难26 / 无限32
  • 升级+1随机增援；全灭后按等级重建，最高不超过难度上限
  • AI步兵出生携带随机装备：简单最多2件 / 普通最多4件 / 困难最多6件；无限难度15分钟前2件、15~30分钟4件、30分钟后6件；AI不能拾取掉落

战场规则

  • 黄圈累计100,000经验者获胜；无限难度无胜利条件
  • 普通50,000/90,000各一位BOSS；困难90,000红绿双BOSS；简单无BOSS
  • 隐蔽1秒、幽灵1秒；反坦克炮/指挥车原地5秒进入隐蔽；指挥车持续侦察圈可见普通隐蔽，不可见幽灵；G键含手雷/火箭筒
  • 工程车选择一种工程模式后行驶布设：反步兵雷 / 反坦克雷 / 铁丝网 / 拒马；工程值在补给点补充
  • 占领区提供掩护、持续经验与分数；工事可独立索敌开火

连队与工事

  • 升级时五选一；分数可购买额外抽卡，首价 200，每次购买涨价 40
  • 工兵可构筑强化工事，或在 100m 内构筑野战工事
  • 每个工事区最多四座工事；补给站由绿色运输机空投，中心补给箱可被摧毁

操作：左键选择 / 框选，右键移动或攻击，双击右键急行军；空格暂停，H 打开帮助。选择战场后点击“开始作战”。

操作与单位数据

2 km × 2 km 战场 · 三张地图 + 试验场 · 等高距 10 米 · 方里网 100 米

操作

  • 左键选择单位 / 拖拽框选
  • 作战简报选择混战模式或背水一战；两种模式都可选简单 / 普通 / 困难 / 无限，混战普通为现有基准
  • Shift + 左键追加或取消选择
  • 右键移动；多单位按最慢单位速度前进；双击 = 步兵急行军
  • 右键敌对攻击并追击
  • Shift + 右键指挥车侦察 / 工兵构筑野战工事 / 狙击小组就地隐蔽 / 火箭炮点射
  • Shift + 右键 指挥车在 600m 内选取一点建立直径 300m 持续侦察区，高地可提高距离；指挥车视野 450m，移动后侦察区失效；原地 5 秒进入隐蔽，移动/开火解除
  • Shift + 右键 火箭炮指定目标点，进入射程后 5 秒内逐发速射 10 发；默认停火，装填 90 秒
  • F3显示/隐藏性能面板：FPS、单位数、更新/渲染耗时、特效数与可见单位
  • 面板技能按钮火力压制 / 侦察 / 投掷/发射 / 就地隐蔽 / 构筑工事：点击后再点地图，等同 Shift + 右键；手雷/火箭筒可切换自动/手动，G 键手动攻击
  • 工程车选中工程车后，在详情面板选择反步兵雷 / 反坦克雷 / 铁丝网 / 拒马；再右键移动，车辆沿行驶路线布设。右键点击敌方铁丝网/拒马可拆除
  • 左侧部队清单点击单位选中并跳转镜头
  • 开火模式已选单位面板可切换自由开火 / 反击 / 停火
  • 底部抽卡升级抽卡先排队，点按钮再选，可稍后再选
  • 顶部 ≡暂停并打开作战菜单：继续 / 重新开始 / 保存 / 读取 / 主动结算 / 回到主菜单 / 音效；同时显示 TOP20 积分榜
  • Shift + 右键选中火炮：对该点火力压制 60 秒
  • WASD / 方向键移动镜头
  • 小地图左键跳转镜头，右键下达移动命令
  • 滚轮 / 中键缩放 / 拖拽平移
  • 空格暂停 / 继续
  • X / F立即停止选中单位（取消移动、攻击、伴随等命令）
  • Ctrl + A全选我军
  • Esc取消选择 / 关闭帮助
  • R重新开始整场战斗

卡包与装备

  • 拖动卡片拖到单位 / 战场使用；拖到丢弃格扔掉
  • 升级抽卡5 张候选进队列，点“抽卡”再选 1 张；顶部全队分数为可用余额，卡包左侧买抽卡首价 200，之后每次涨价 40；购买只增加次数，不自动打开界面
  • 单位包 / 装备包 / 工事包自动开包，直接变成对应卡片
  • 装备卡拖到步兵班，占用 1 个物品栏，不消耗弹药
  • 补给站绿色运输机空投 200m 补给圈：中心 500 HP 补给箱可被炮火/空袭击毁；补弹药 / 步兵 25HP/s 医疗 / 车辆 20HP/s 维修，并给己方工事补弹和维修；弹药 2500 / 维修量 2000
  • 工兵装备12 秒构筑强化工事；Shift+右键 100m 内建野战工事；残骸 8 秒修复
  • 机枪碉堡 / 迫击炮阵地 / 反坦克炮阵地 / 88防空炮阵地拖到强化工事区，提供额外火力；每区最多 4 座，可同类重复或混搭，无需步兵驻守即可开火
  • 阵地射程碉堡/迫击炮/反坦克炮/88炮的射程圈在地图常显，工事被毁后消失，修复后恢复
  • 物品栏共 6 格；装备可拖到丢弃格卸下

混战模式四档难度：普通为现有基准；困难 / 无限会提高敌方经验、火力与进攻欲望。混战无限难度没有胜利条件；简单难度无BOSS，普通在50000/90000黄圈经验各召唤一位BOSS，困难在50000召唤一位、90000红绿双方各一位，无限模式50000召唤一次后AI重生按时间概率召唤。背水一战每5波加入BOSS，第30波双BOSS，第50波起三BOSS；刷新时屏幕上方显示 BOSS 名称与比例血条，不显示具体数值。第 1 波即有低权重火炮，之后每 5 波略微提高火炮、防空车与重型坦克权重；击杀地狱轰炸机/超级重坦奖励 10000 经验/10000 分/6 张单位卡，幽灵兵团按步兵班分别结算，整组全灭再额外奖励。新增「制空盘旋」：3 架战斗机以直径 500m 盘旋 40 秒，地图显示制空圈与倒计时；敌机进入空域后追击到后方 100m；无对空目标时扫射地面步兵、装甲车和火炮。仅侦察机自带 200m 视野，侦察持续 20 秒。无限模式提供结算 / 存档 / 读档。AI 只有装备工兵装备的步兵占领占领区，才会形成强化工事与武器；工事武器数量为简单1 / 普通2~3 / 困难4 / 无限按时间2、4、4（上限4）。AI 步兵装备上限：简单2 / 普通4 / 困难6，无限15分钟前2、15~30分钟4、30分钟后6。AI 步兵班阵亡时有 15% 概率掉落装备，玩家步兵班阵亡时有 15% 概率从已装备物品中掉落 1~2 件，步兵踩过可拾取，2 分 30 秒未拾取则消失。所有轰炸机投弹前都会显示红色落点圈、杀伤直径与到达倒计时。迫击炮优先瞄准软目标。
